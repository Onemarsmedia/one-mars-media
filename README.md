# One Mars Media

A modern, dark-themed homepage for One Mars Media, a London-based video production and AI content studio.

Built with Next.js, Tailwind CSS, and Framer Motion.

## About

This homepage showcases One Mars Media's studio services, featuring:
- Bold hero section with studio branding and call to action
- Services for Commercial Video, AI UGC Content, AI Coaching, Social Content
- Studio bio with 13 years of experience and global brand work
- Performance stats for views and interactions
- Contact section with discovery call CTA and email

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
